# loc-apps
Home-screen launchers for LOC staff iPads (icon + full screen). **Public repo: no code, no secrets, no app addresses.**
The Apps Script web-app id is added after `#` on each iPad when the icon is added to the Home Screen.
- `order/` — ORDER (LIQUORLAND ORDER APP · CH2)
- `delivery/` — DELIVERY (LIQUORLAND DELIVERY staff app · CH4 · icon from liquorland-delivery delivery/_assets)

Both pages re-open themselves when the app sends `{locApp:'reload'}` (new version → Update now). Only google.com / googleusercontent.com may send it.
